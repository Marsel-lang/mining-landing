# TTM Mining — Landing Page

Адаптивный лендинг о современных решениях для майнинга. Проект начинался как дизайн-макет в Tilda, после чего был перенесён в самостоятельную веб-версию на HTML, CSS и JavaScript и опубликован через GitHub Pages.

## Демо

[Открыть сайт](https://marsel-lang.github.io/mining-landing/)

## О проекте

Сайт представляет бренд TTM / To The Moon и знакомит посетителей с направлением майнинга, преимуществами и основными предложениями.

## Реализация

- HTML — структура страниц
- CSS — оформление и адаптивная вёрстка
- JavaScript — интерактивные элементы и поведение интерфейса
- GitHub Pages — публикация сайта

## Этапы

1. Разработка первоначальной концепции и макета в Tilda.
2. Подготовка самостоятельной версии сайта.
3. Адаптация интерфейса под мобильные устройства.
4. Публикация проекта на GitHub Pages.
