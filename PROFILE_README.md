## Проекты

### TTM Mining — Landing Page
Адаптивный сайт о майнинге. Начальная концепция создавалась в Tilda, затем проект был реализован на HTML, CSS и JavaScript.
- [Открыть сайт](https://marsel-lang.github.io/mining-landing/)
- [Исходный код](https://github.com/Marsel-lang/mining-landing)

### TTM UI Kit
Дизайн-система TTM: цветовая палитра, типографика, кнопки, карточки, статусы и система отступов.
- [Посмотреть проект](https://github.com/Marsel-lang/mining-landing/tree/main/ui-kit)

### TTM Calculator
Веб-калькулятор для оценки доходности ASIC-майнинга с учётом оборудования, электричества и комиссии пула.
- [Открыть калькулятор](https://marsel-lang.github.io/ttm-calc/)
- [Исходный код](https://github.com/Marsel-lang/ttm-calc)
