# TTM UI Kit

Небольшая веб-страница дизайн-системы TTM / To The Moon. В ней собраны базовые визуальные правила и примеры компонентов интерфейса.

## Демо

[Открыть UI Kit](https://marsel-lang.github.io/mining-landing/ui-kit/)

## Содержание

- Цветовая палитра
- Типографика
- Стили кнопок
- Поля и элементы интерфейса
- Карточки и статусы
- Система отступов

## Визуальная система

Основные цвета:

- Background — `#101010`
- Surface — `#1A1A1A`
- Surface Light — `#242424`
- Border — `#333333`
- Orange — `#FF781F`
- Orange Light — `#FF9A45`

## Технологии

- HTML
- Tailwind CSS
- CSS
- Google Fonts (Inter)

Страница использует Tailwind CSS Browser CDN для демонстрации дизайн-системы.

**Тип:** UI Kit / Design System  
**Версия:** 1.0
